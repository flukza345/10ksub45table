01 Pace เป้าหมาย

Race pace เป้าใหม่ = 4:25/กม. (= 44:10) ตั้งเผื่อ buffer ให้ sub-45 ชัวร์ (PB 10K ปัจจุบัน 46:56 ห่างเป้าเพียง ~2 นาที)
ประเภทPace (นาที/กม.)อ้างอิง / ใช้ตอนไหน
Race pace (RP)4:25เป้าแข่ง = 44:10 (buffer ก่อน 45:00)
Interval / VO₂max (I)3:55–4:05ใกล้ 5K pace (4:12) — ความเร็วมีเหลือ
Threshold / Tempo (T)4:30–4:40หัวใจของแผน ยกเพดานความทน ค้างได้ 20–40 นาที
Easy (E)5:45–6:30pace ฟื้นฟูที่ทำอยู่แล้ว (6:27) ถูกต้อง
Long run (L)5:20–5:50base แน่น เริ่มกลางช่วง easy ได้

03 วอร์มอัพ (ก่อนซ้อมทุกวัน)

ขั้นที่ 1 — จ็อกเบา

รายการวันเร็ว/แข่งวัน easy/long
จ็อกช้ามาก @6:30–7:0010–12 นาที5 นาที (หรือเริ่มช้าแล้วค่อยเร่ง)

ขั้นที่ 2 — Dynamic stretching (เน้นวันเร็ว) ทำช้าๆ มีจังหวะ ไม่ค้าง

ท่าจำนวนวิธีทำ
Leg swing หน้า-หลัง12 ครั้ง/ขาจับผนัง แกว่งขาหน้า-หลังสุดช่วง ควบคุมจังหวะ
Leg swing ซ้าย-ขวา12 ครั้ง/ขาแกว่งขาข้ามหน้าลำตัว เปิดสะโพก
Walking lunge + บิดตัว8 ครั้ง/ขาก้าวลันจ์แล้วบิดลำตัวไปด้านขาหน้า
Hip opener (เตะเข่าเปิดออก)8 ครั้ง/ขายกเข่าขึ้นแล้วเปิดออกข้าง เป็นวงกลม
Ankle circles + calf raise เดิน10 ครั้ง/ข้างหมุนข้อเท้า + เขย่งเดินกระตุ้นน่อง

ขั้นที่ 3 — Running drills (เฉพาะวันเร็ว อ./พฤ. และวันแข่ง)

ท่าจำนวนวิธีทำ
A-skip2×20 เมตรสกิปยกเข่าสูง จังหวะเร็ว เท้าลงกลางฝ่าเท้า
B-skip2×20 เมตรเหมือน A-skip แต่เหยียดขาออกก่อนตวัดลง
High knees2×15 เมตรยกเข่าสูงระดับสะโพก แขนแกว่งเร็ว
Butt kicks2×15 เมตรตวัดส้นแตะก้น ลำตัวตั้งตรง

06 ตารางฟื้นฟู (Recovery)

รายการวันรายละเอียด
พักเต็ม (ไม่วิ่ง)เสาร์พัก 1 วันก่อน long run อาทิตย์ · นอน 7.5–8 ชม.
Active recovery (วิ่งเบา)จันทร์ + พุธ + ศุกร์Easy ช้าๆ ล้างของเสีย เลือดไหลเวียน (จันทร์/ศุกร์ สั้น-ช้าจริง 3–5 กม. @6:30)
ยืด dynamicก่อนวิ่งทุกครั้งดูหัวข้อวอร์มอัพ
ยืด staticทุกวันหลังวิ่ง + จันทร์ค้างท่าละ 30 วิ/ข้าง (ดูหัวข้อคูลดาวน์)
โฟมโรลเลอร์ / นวดกดจันทร์ + หลัง long run (อา.)น่อง IT band quad ฝ่าเท้า 8–10 นาที
DeloadW6ลดปริมาณ ~30% ให้ร่างกายซ่อมแซมก่อนเข้า peak
การนอน (จุดที่ต้องแก้)ทุกคืนเป้า 7.5–8 ชม. (ปัจจุบัน ~6.5 ชม.) ตัวฟื้นฟูที่ให้ผลมากที่สุด
HRV / Body Batteryเช็คทุกเช้าถ้า HRV ตกต่ำกว่าปกติ หรือ Body Battery ตื่นมา <30 → เปลี่ยนจันทร์/พุธเป็นพักแทนได้
โซน HR เป้าทุกการวิ่งeasy HR <145 · threshold ~165–172 · interval >175 (ปรับตาม HR max จริง)

สัญญาณต้องพักเพิ่ม: ชีพจรเช้าสูงผิดปกติ, นอนไม่หลับ, ปวดเฉพาะจุดเกิน 2 วัน, หมดแรงเรื้อรัง → ลดความหนักหรือพักเพิ่ม 1 วัน อย่าฝืน

07 คำแนะนำโภชนาการ

ช่วงเวลาคำแนะนำ
ก่อนซ้อม (1.5–2 ชม.)คาร์บย่อยง่าย + โปรตีนเล็กน้อย เช่น ข้าว/ขนมปัง + ไข่ + กล้วย · ถ้าซ้อมเช้าเร่งด่วน กินกล้วยหรือขนมปัง 1 ชิ้นก่อน 30–45 นาที
ระหว่างซ้อมซ้อม <60 นาที จิบน้ำพอ · long run >75 นาที เติมเจล/น้ำเกลือแร่ทุก 40–45 นาที (คาร์บ 30–60 กรัม/ชม.)
หลังซ้อม (ภายใน 30–60 นาที)คาร์บ:โปรตีน ~3:1 เช่น นมช็อกโกแลต, ข้าว+ไก่/ปลา, โยเกิร์ต+ผลไม้ ฟื้นฟูไกลโคเจน + ซ่อมกล้ามเนื้อ
รายวันคาร์บ 5–7 กรัม/กก.น้ำหนักตัว · โปรตีน 1.4–1.8 กรัม/กก. · ไขมันดี + ผักผลไม้หลากสี · ธาตุเหล็ก (นักวิ่งเสี่ยงขาด)
เติมน้ำดื่มน้ำสม่ำเสมอทั้งวัน (ปัสสาวะสีอ่อน) · ชั่งน้ำหนักก่อน/หลัง long run ทุก 1 กก.ที่หาย = ดื่มทดแทน ~1.5 ลิตร
3 วันก่อนแข่งเพิ่มคาร์บเป็น 7–8 กรัม/กก. (carb loading เบาๆ) ลดใยอาหารหยาบ ลดของมัน/ทอด
เช้าวันแข่ง (3 ชม.ก่อนออกตัว)อาหารคุ้นเคยคาร์บสูง ย่อยง่าย เช่น ข้าวต้ม/ขนมปัง+แยม+กล้วย ~500–600 แคล · จิบน้ำ 400–500 มล. · งดของใหม่ที่ไม่เคยลอง
ระหว่างแข่ง 10Kระยะสั้น ไม่จำเป็นต้องกินเจล · จิบน้ำที่จุดพักถ้าอากาศร้อน · ถ้าเคยชินคาเฟอีน กาแฟ 1 แก้วก่อนออกตัว ~45 นาทีช่วยได้
หลังแข่งเติมคาร์บ + โปรตีน + น้ำ + เกลือแร่ภายใน 1 ชม. ยืดเบาๆ เดินคูลดาวน์

08 วิธีอ่านตาราง

สูตรการอ่าน: [จำนวนเที่ยว] × [เวลา/ระยะต่อเที่ยว] @[pace] พัก [เวลาพัก]
ตัวอย่าง: 2×10' @4:40 พัก 2' = ทำ 2 รอบ, รอบละ 10 นาที, ที่ pace 4:40/กม., พักระหว่างรอบ 2 นาที
เครื่องหมายความหมายตัวอย่าง
×"คูณ" = จำนวนรอบที่ทำซ้ำ6×800ม = วิ่ง 800 ม. 6 เที่ยว
' (ขีดเดียว)นาที10' = 10 นาที · พัก 2' = พัก 2 นาที
" (ขีดคู่)วินาทีพัก 90" = พัก 90 วินาที
มเมตร (ระยะ)800ม = 800 เมตร
@"ที่ pace" (นาที:วินาที ต่อ 1 กม.)@4:25 = ที่ pace 4 นาที 25 วินาที/กม.
พักช่วงพักระหว่างเที่ยว (จ็อกเบาหรือเดิน)พัก 2' = จ็อก/เดิน 2 นาทีก่อนเริ่มเที่ยวถัดไป

💡 นาฬิกา Garmin โชว์ pace แบบ real-time อยู่แล้ว — แค่คุมให้ pace ตรงกับ @ ที่ระบุตอนวิ่งช่วงเร็ว · Tempo วัดเป็นเวลา (เช่น 2×10') · Interval วัดเป็นระยะ (เช่น 6×800ม)

09 อธิบายทุกประเภท session

1. Interval (วันอังคาร)

คืออะไร: วิ่งเร็วเป็นช่วงสั้นๆ วัดเป็นระยะ สลับกับพักเต็ม เพื่อพัฒนาความเร็วและ VO₂max
วิ่งเท่าไร / pace: เช่น 6×800ม @4:00 พัก 2' = 800 เมตร 6 เที่ยว ที่ pace 4:00/กม. (เร็วกว่า race pace) พักระหว่างเที่ยว 2 นาที · ระยะต่อเที่ยวอยู่ที่ 400–1500 ม. ตามสัปดาห์
จุดประสงค์: ยกเพดานความเร็วสูงสุด ทำให้ race pace 4:25 รู้สึก "สบายขึ้น" เพราะเคยวิ่งเร็วกว่านั้นมาแล้ว
วิธีอ่าน: [เที่ยว]×[ระยะ ม.] @[pace] พัก [เวลา] — ความเร็วมาก่อน พักให้หายเหนื่อยพอก่อนเที่ยวถัดไป

2. Tempo / Threshold (วันพฤหัส)

คืออะไร: วิ่งเร็วปานกลาง-หนักต่อเนื่องเป็นช่วงเวลานานๆ ("หนักแบบสบาย" พูดเป็นคำสั้นๆ ได้) วัดเป็นเวลา
วิ่งเท่าไร / pace: เช่น 2×10' @4:40 พัก 2' = 10 นาที 2 รอบ ที่ pace 4:40/กม. พัก 2 นาที · หรือต่อเนื่องรวดเดียว เช่น 1×25' @4:40 = วิ่ง 25 นาทีรวด ไม่มีพัก
จุดประสงค์: ยก lactate threshold (จุดที่ร่างกายเริ่มล้า) ให้สูงขึ้น = หัวใจของแผนสำหรับคนที่ความเร็วพอแล้วแต่ต้องเพิ่มความทนที่ race pace
วิธีอ่าน: [รอบ]×[เวลา นาที] @[pace] พัก [เวลา] — เน้นค้าง pace นิ่งๆ นานๆ ไม่ต้องเร็วสุด

3. Easy (จันทร์ / พุธ / ศุกร์)

คืออะไร: วิ่งช้าสบาย พูดคุยได้เต็มประโยค — ไม่ใช่วันเก็บความเร็ว
วิ่งเท่าไร / pace: 3–8 กม. ที่ pace 5:45–6:30/กม. (จันทร์/ศุกร์ สั้น-ช้าจริง 3–5 กม. @6:30 เป็น active recovery)
จุดประสงค์: สร้าง aerobic base, ล้างของเสีย, ให้เลือดไหลเวียนฟื้นฟูกล้ามเนื้อ โดยไม่เพิ่มความล้า
วิธีอ่าน: Easy [ระยะ กม.] @[pace] — ช้าไว้ก่อน ถ้ารู้สึกเหนื่อยแปลว่าเร็วเกิน

4. Long run (วันอาทิตย์)

คืออะไร: วิ่งระยะยาวสุดของสัปดาห์ สร้างความทนทาน (endurance)
วิ่งเท่าไร / pace: 11–16 กม. ที่ pace 5:20–5:50/กม. · บางสัปดาห์มีช่วงท้ายเร่ง เช่น Long 15 กม. (5 กม.ท้าย @4:40) = วิ่ง 15 กม. โดย 5 กม.สุดท้ายเร่งเป็น pace 4:40
จุดประสงค์: เพิ่มความทนของกล้ามเนื้อและระบบพลังงาน ฝึกใจให้ชินกับการวิ่งนาน + ช่วงท้ายเร่งคือฝึกวิ่งเร็วตอนขาล้า (เหมือนช่วงท้ายการแข่ง)
วิธีอ่าน: Long [ระยะ] @[pace] หรือมีวงเล็บบอกช่วงเร่งท้าย

5. Race-pace / Time trial (ช่วง Peak)

คืออะไร: ซ้อมที่ pace แข่งจริง (4:25) เพื่อให้ร่างกายจำความรู้สึกของวันแข่ง · Time trial = ทดสอบวิ่งจริงจัง
วิิ่งเท่าไร / pace: เช่น 5×1200ม @4:25 (RP) พัก 90" = 1200 ม. 5 เที่ยวที่ race pace พัก 90 วินาที · Time trial 8 กม. @4:25 = วิ่ง 8 กม. รวดที่ race pace เพื่อวัดความพร้อม
จุดประสงค์: ปรับร่างกาย+จังหวะให้คุ้นกับ race pace ก่อนแข่ง · ถ้า time trial 8 กม. @4:25 ทำได้สบาย = พร้อม sub-45
วิธีอ่าน: (RP) = Race Pace = 4:25/กม.

6. เวท A / เวท B (ต่อท้าย Interval และ Tempo)

คืออะไร: ฝึกความแข็งแรงด้วยดัมเบล 5 กก. + ยางยืด ทำต่อท้ายวันวิ่งเร็วเท่านั้น (อ./พฤ.)
ทำเท่าไร: เวท A (อังคาร): Goblet squat 3×12, RDL 3×12, Reverse lunge 3×10/ขา, Glute bridge+ยางยืด 3×15, Plank 3×40วิ · เวท B (พฤหัส): Bulgarian split squat 3×10/ขา, Single-leg calf raise 3×15/ข้าง, Banded lateral walk 3×12/ข้าง, Dumbbell step-up 3×10/ขา, Side plank 3×30วิ/ข้าง, Banded clamshell 2×15/ข้าง (ดูตารางเวทด้านบน)
จุดประสงค์: เพิ่มความแข็งแรงขา/สะโพก/แกนกลาง ป้องกันบาดเจ็บ และวิ่งได้มีประสิทธิภาพขึ้น
วิธีอ่าน: [เซ็ต]×[ครั้ง] เช่น 3×12 = 12 ครั้ง 3 เซ็ต พักระหว่างเซ็ต 60–90 วินาที

7. Recovery (ทุกวัน + วันพัก)

คืออะไร: การฟื้นฟูร่างกาย ทั้งแบบ active (วิ่งเบา) และ passive (พัก/ยืด/โฟมโรลเลอร์)
ทำเท่าไร: พักเต็ม = เสาร์ (ไม่วิ่ง) · active recovery = จันทร์/พุธ/ศุกร์ (Easy ช้าๆ) · โฟมโรลเลอร์ 8–10 นาที (จันทร์ + หลัง long run) · static stretch ทุกวันหลังวิ่ง ค้างท่าละ 30 วินาที
จุดประสงค์: ให้ร่างกายซ่อมแซมและแข็งแรงขึ้นจริง — การพัฒนาเกิดตอนพัก ไม่ใช่ตอนซ้อม ถ้าไม่ฟื้นพอจะ overtraining
วิธีอ่าน: 🧘 ในตาราง = ทำ recovery วันนั้น · เช็ค HRV/Body Battery ทุกเช้า ถ้าตกให้เปลี่ยนวิ่งเบาเป็นพัก
แผนนี้ตั้งอยู่บนสมมติฐานว่าไม่มีอาการบาดเจ็บ · ระหว่างฝึกให้เชื่อ HRV / Body Battery ของ Garmin เป็นตัวตัดสินว่าวันไหนควรถอย · ปรับความหนัก/ปริมาณตามสภาพร่างกายจริง
